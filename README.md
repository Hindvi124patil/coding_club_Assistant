🤖 Coding Club Assistant

Learn to Code. Debug Smarter. Build Together.

Coding Club Assistant is an AI-powered web application designed to help college students learn programming, solve coding problems, debug errors, and improve their problem-solving skills. It serves as a virtual coding mentor for students at beginner, intermediate, and advanced levels.

The platform aims to make programming easier through AI-powered guidance, coding practice, personalized learning roadmaps, and support for technical interviews and hackathons.

✨ Key Features

- 🤖 AI Coding Mentor: Get help understanding programming concepts and solving coding doubts.
- 🐛 Code Debugging: Identify coding errors and understand possible solutions.
- 💻 Code Playground: Explore and work with programming code.
- 🧩 Coding Practice: Improve problem-solving skills with coding challenges.
- 🗺️ Personalized Roadmap: Follow a structured path to learn programming.
- 🎯 Challenge Generator: Practice coding through problem-solving activities.
- 📊 Progress Tracking: Monitor learning progress and encourage consistent practice.
- 🏆 Hackathon Preparation: Build technical confidence and prepare for coding competitions.
- 📱 User-Friendly Interface: Access learning features through a modern interface.

🛠️ Technology Stack

- Frontend: React and TypeScript
- Backend: Node.js
- AI Integration: Google Gemini API
- Development Platform: Google AI Studio

🎯 Project Objectives

- Make programming easier and more accessible for students.
- Help learners understand coding errors and improve their code.
- Encourage regular coding practice and logical thinking.
- Provide structured learning guidance for different skill levels.
- Support students in preparing for interviews and hackathons.
